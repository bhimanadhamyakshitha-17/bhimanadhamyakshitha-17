### 2. ResQLink 🚨

**ResQLink** is a disaster and emergency assistance prototype designed to help people submit emergency requests and receive information about assistance.

**Key Features:**
- Submit emergency assistance requests.
- Select the type of emergency from predefined options.
- Categorize requests based on priority.
- Display request acceptance status.
- Provide location and estimated arrival information in the prototype.

**Objective:** To simplify emergency request submission and improve communication between people requesting assistance and responders.
